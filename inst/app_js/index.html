  • This page is plain JavaScript running in your browser. Files you choose are read here and are not uploaded.
  • It makes no requests to other sites: no analytics, no proxy, no fonts or scripts from elsewhere.
  • A browser check on every build confirms this, and the page's own policy tag allows only this site.
  • The only links that leave this page are the API links in step 2, and only if you click them.
  • The vendor's server does not let a web page read those links directly, so you open each one, save the JSON, and drop the files here.
  • A bundle holds your raw session data. Keep it private; closing this tab forgets everything.
  • Merging: a session already in the bundle (same match id) is replaced by the newer copy.
  • Charts start with a synthetic sample, not real data.
  • The R package rallyr is the reference: this page repeats its calculations in JavaScript, and a test on every build checks that both give the same numbers. A bundle saved here opens in R, and the other way round.
