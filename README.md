# rallyr

`rallyr` parses tennis practice-session exports from the
[SwingVision](https://www.swingvision.com/) app — either its public
share-link API or a raw copy-pasted match/rally page — into a tidy
DuckDB database, and computes derived per-rally and per-session metrics
(rally splitting, data-quality flags, standardised effort scores). It ships
with a synthetic sample dataset, so the quick-start example below runs with
no real session data of any kind.

## Installation

Not yet published. Once published:

```r
# install.packages("pak")
pak::pak("owner/rallyr")
```

## Quick start

Generate the bundled synthetic sample database (run once, from the package
root):

```r
Rscript data-raw/generate_sample.R
```

Then explore it:

```r
library(rallyr)

db_path <- system.file("extdata", "synthetic_sample.duckdb", package = "rallyr")
con <- tennis_db_connect(db_path)

matches <- tennis_matches(con)
matches

schema <- tennis_db_schema(con)   # structure only -- table/column names and types
schema

DBI::dbDisconnect(con, shutdown = TRUE)
```

To parse your own data instead:

```r
# From a SwingVision public share link/token:
match <- fetch_swingvision("https://swing.vision/matches/sw2-...", me = "Your Name")

# From text copied off a SwingVision match/rally page:
matches <- parse_swingvision(pasted_text)
```

## What this package does and does not do

- Parses and stores session-level and shot-level SwingVision data.
- Computes derived metrics: rally splitting (`find_rally_splits()`),
  data-quality flags (`dq_flag_rallies()`, `dq_corrected_rallies()`),
  drill-phase segmentation (`segment_session_shots()`), and standardised
  per-session effort scores (`session_effort_metrics()`).
- Does **not** ship, fetch, or require any real session data — the bundled
  example uses a synthetic dataset generated by `data-raw/generate_sample.R`
  from hand-picked random distributions, never fitted to or derived from
  any real dataset.
- Does **not** provide a dashboard or web UI. It is the data layer a
  dashboard (Shiny, Quarto, or otherwise) can be built on top of.
